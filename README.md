# Dota Pick

Программа для драфта: отмечаешь врагов и свою команду — она показывает, кого пикнуть и что собрать на твою позицию.
Без ИИ и без ключей: только открытые данные OpenDota.

## Запуск
Двойной клик по **Dota Pick.bat**. Откроется отдельное окно. Закрыл окно — программа выключилась сама.
Нужен Python 3 и интернет. При первом запуске данные качаются ~2 минуты, потом берутся из кэша.

## Как пользоваться
- **Враги / Мы** — 5 слотов сверху. Слот «Я» — твой герой, остальные — тиммейты.
- Герои сгруппированы по атрибутам: **Сила, Ловкость, Интеллект, Универсальные**. Кнопки **Все · 1–5** справа от поиска
  подсвечивают только героев этой роли. Имя героя — при наведении.
- Добавить героя: начни печатать имя (можно по-русски и сленгом: пудж, фантомка, ам) — нужный подсветится —
  **Enter** во врагов, **Shift+Enter** в союзники. Мышью: **клик** — во врагов, **правый клик** — в союзники.
- Кликнуть по пустому слоту — следующий герой встанет именно туда. Кликнуть по герою в слоте — убрать.
- **Моя позиция** — советует героев только на эту роль и показывает сборку под неё.
- Пока «Я» пустой — «Кого пикнуть»: плюс против всей команды и цифра против каждого врага
  (зелёная рамка — синергия с тиммейтом). Клик по герою — его сборка, **«Беру»** — ставит в слот «Я».
- Когда «Я» заполнен — как твой герой стоит против их команды и сборка.
- В сборке есть вкладки **1–5 поз.** с числом игр — переключай, закупы на каждой позиции свои.

## Откуда цифры
- **Контрпики и синергия** — ~300 тыс. ранговых матчей Archon–Legend за последние сутки. Обновляются раз в день.
- **Сборки по позициям** — про-матчи текущего патча с логом покупок (~9 тыс. матчей). Позиция игрока
  определяется по линии и фарму в команде. Если на позиции меньше 15 игр — показывается общая сборка героя.
  Обновляются раз в неделю.
- **Против этой команды** — ситуативные предметы против конкретных врагов; сверху те, что закрывают нескольких.

Кэш: `stats.json`, `builds.json`. Ошибки, если будут, — в `app.log`. Проверка: `python test_app.py`

## Виджет в Телеграме (Mini App)
Та же программа, но открывается кнопкой внутри бота — на телефоне и на компьютере.
- `site/index.html` — сам виджет (вся логика внутри страницы, сервер не нужен).
- `build_data.py` — готовит `site/data.json` со всеми данными. Локально: `python build_data.py --cache`.
- `.github/workflows/pages.yml` — GitHub каждый день в 07:00 МСК качает свежие данные и выкладывает виджет
  на GitHub Pages (бесплатно). Если загрузка не удалась — остаётся вчерашняя версия.

Как включить:
1. GitHub → **New repository** → имя `dota-pick`, **Public** → Create. Загрузить в него эту папку.
2. В репозитории: **Settings → Pages → Source: GitHub Actions**.
3. **Actions → «Обновить Dota Pick» → Run workflow**. Через 2–3 минуты виджет будет по адресу
   `https://<твой-логин>.github.io/dota-pick/`.
4. Телеграм → **@BotFather** → `/mybots` → бот → **Bot Settings → Menu Button → Configure menu button** →
   отправить адрес из шага 3 → отправить название `Dota Pick`. Слева от поля ввода в боте появится кнопка.

GitHub отключает расписание, если в репозитории 60 дней не было изменений (придёт письмо).
Тогда: **Actions → «Обновить Dota Pick» → Enable workflow**.
