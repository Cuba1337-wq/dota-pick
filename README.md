# Dota Pick

Программа для драфта: отмечаешь врагов и свою команду — она показывает, кого пикнуть и что собрать на твою позицию.
Без ИИ и без ключей: только открытые данные OpenDota.

## Запуск
Двойной клик по **Dota Pick.bat**. Откроется отдельное окно. Закрыл окно — программа выключилась сама.
Нужен Python 3 и интернет. При первом запуске данные качаются ~2 минуты, потом берутся из кэша.

## Как пользоваться
- **Враги / Мы** — по 5 слотов, каждый слот — позиция: Керри, Мид, Хардлайн, Поддержка, Полная поддержка.
- **Я играю** — выбери свою позицию: твой слот подсветится, и советы будут под неё.
- Начни писать имя героя (можно по-русски и сленгом: «баб» → Snapfire) — сразу появятся подсказки.
  Клик по подсказке или **Enter** — добавить. Куда — переключатель **Враги / Мы** рядом с поиском
  (на ПК ещё **Shift+Enter** и правый клик — в «Мы»). Герой сам встаёт на свою обычную позицию.
- Клик по пустому слоту — следующий герой встанет именно туда. Клик по герою в слоте — убрать.
- **Кого пикнуть** — лучшие герои против всей их команды; цифры — против каждого врага (зелёная рамка — синергия).
  **«Беру»** — ставит героя в твой слот.
- **Сборка**: старт, **порядок закупа с минутой** (когда обычно покупают и сколько % игроков), предметы по ситуации,
  предметы против их команды и **советы** по герою и матчу. Вкладки позиций — закупы для каждой позиции свои.

Программа на ПК и виджет в Телеграме — **один и тот же интерфейс** (`site/index.html`): правишь один файл — меняется везде.
Порядок закупа можно поправить вручную: `ORDER_RULES` в `heroes_data.py` (например, Legion Commander — сначала Blink).

## Виджет в Телеграме (Mini App)
Та же программа, но открывается кнопкой внутри бота — на телефоне и на компьютере.
- `site/index.html` — интерфейс (общий с программой на ПК, вся логика внутри страницы).
- `build_data.py` — готовит `site/data.json` со всеми данными. Локально: `python build_data.py --cache`.
- `.github/workflows/pages.yml` — GitHub каждый день в 07:00 МСК качает свежие данные и выкладывает виджет
  на GitHub Pages (бесплатно). Если загрузка не удалась — остаётся вчерашняя версия.

Как включить:
1. GitHub → **New repository** → имя `dota-pick`, **Public** → Create. Загрузить в него эту папку.
2. В репозитории: **Settings → Pages → Source: GitHub Actions**.
3. **Actions → «Обновить Dota Pick» → Run workflow**. Через 2–3 минуты виджет будет по адресу
   `https://<твой-логин>.github.io/dota-pick/`.
4. Телеграм → **@BotFather** → `/mybots` → бот → **Bot Settings → Menu Button → Configure menu button** →
   отправить адрес из шага 3 → отправить название `Dota Pick`. Слева от поля ввода в боте появится кнопка.

GitHub отключает расписание, если в репозитории 60 дней не было изменений (придёт письмо).
Тогда: **Actions → «Обновить Dota Pick» → Enable workflow**.
